## Yang dibuat

- **`scripts/siapkan-crawler.mjs`** — `kompilasiBytecode`: `python -m compileall -j 0 --invalidation-mode
  unchecked-hash` atas `python/Lib` & `crawler/` di bundel, sebelum uji. `unchecked-hash`: bundel tak diubah sesudah
  dipasang (pembaruan = bundel baru), jadi pyc tak divalidasi ke waktu berkas yang ditulis pemasang. `tanpaBytecode`:
  build **gagal** bila ada `.py` tanpa pyc. Waktu jabat tangan MCP kini dicatat di log build. Ukuran: pyc 52 MB di
  disk (runtime lokal 206 MB), **±15 MB** di pemasang (diukur dengan 7-Zip `-mx=9` seperti electron-builder).
- **`konektorMcp.cjs`** — `BATAS.sambungMs` 30 → **90 s** (hanya untuk server yang benar-benar macet).
- **Settings › Konektor** — saat menyala: "menyalakan… (di komputer lambat bisa sampai semenit)".
- Ikut terbawa: alamat folder data di dialog stealth disusun dari folder sebenarnya (`e6eaf39`).
- Versi 4.3.0 → **4.3.1**.
