# 26 Oktober 2026 — Rilis 4.3.0: build GitHub membangun crawler terbundel (Item 129)

Owner meminta versi dinaikkan ke **4.3.0** supaya Mamet AI dengan konektor bisa diunduh di laptop lain.

## Masalah yang ditemukan sebelum menaikkan versi

Kenaikan versi di `frontend/package.json` adalah pemicu `build.yml` (GitHub Actions, `windows-latest`), yang
menjalankan `npm run dist:publish`. Sejak Tahap E, `dist:publish` menjalankan `crawler:siapkan`, yang menyalin Python
dan paket dari `capability/ecosystem-crawler/.venv`. `.venv` **tidak di-commit** (repo publik) — mesin build tidak
memilikinya, sehingga build akan berhenti dengan galat ".venv crawler tidak ada" dan **tidak ada pemasang yang terbit**.
Ini disampaikan ke Owner sebelum versi dinaikkan; rencana di bawah disetujui Owner.

## Yang dibuat

- **`capability/ecosystem-crawler/requirements-bundel.txt`** — `pip freeze --all` dari `.venv` yang sudah diuji: 86
  paket berversi pasti (83 yang dibundel + patchright, playwright, pytest — dibuang penyiap dari bundel, tetap dicatat
  supaya `.venv` build sama persis; versi patchright = `stealth.json`). `pyproject.toml` hanya mengunci 9 paket utama;
  tanpa daftar ini dependensi turunan bergeser ke versi hari itu, kombinasi yang belum pernah diuji.
- **`.github/workflows/build.yml`** — sebelum build: `actions/setup-python` **3.12.10** (sama dengan `.venv` Owner),
  `python -m venv .venv`, `pip install --no-deps -r requirements-bundel.txt`. Unduhan paket terjadi di mesin GitHub.
- **`scripts/siapkan-crawler.mjs`** — `periksaPythonTerbundel`: build **gagal** bila Python terbundel tidak membawa
  `python.exe`, `python3XX.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`. Pustaka C++ itu yang membuat python.exe
  jalan di PC tanpa Visual C++ Redistributable; ketiadaannya tak akan terlihat di mesin pembangun (DLL-nya ada di
  System32) — terkait pertanyaan Owner soal laptop yang benar-benar bersih.
- **Versi** `frontend/package.json` & `package-lock.json`: 4.2.16 → **4.3.0**.

Muatan 4.3.0 (sejak 4.2.16): Item 129 Tahap A–E3 — Settings › Konektor, klien MCP, gerbang persetujuan, pemasang
membawa Python + Ecosystem Crawler, tombol pasang komponen stealth, daftar yang terpasang + Buka folder.

## Bukti (sebelum push)

- `uji-konektor-komponen.mjs` v2 bagian 8: pemeriksaan DLL (berkas kosong → semua disebut; nama tak peka huruf besar),
  penyiap gagal bila ada yang hilang, setiap baris daftar kunci berversi pasti, `build.yml` memasang daftar dengan
  `--no-deps` sebelum `dist:publish`, Python `build.yml` = Python `.venv` (3.12.10), setiap paket `.venv` & setiap
  paket bundel tercantum dengan versi sama, versi patchright = `stealth.json`, runtime sungguhan membawa keempat
  berkas wajib. Dua mutasi menggigit (pengaman DLL dimatikan; satu versi di daftar kunci digeser).

## Belum dibuktikan

  `mamet334/mamet-ai-releases`), bukan disimpulkan dari dokumen ini. Rilis terbit sebagai draf; sampai ke aplikasi
  terpasang sesudah Owner menekan Publish.
- Pemasang 4.3.0 di PC bersih (Windows Sandbox).
